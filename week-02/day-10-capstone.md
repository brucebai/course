## 📚 Core Concepts

### Capstone 项目说明

今天的课程是一个综合练习：你将为一个**真实的业务场景**设计 Agent Harness 架构。

这不是纸上谈兵——你设计的架构，应该是一个你真正想要构建或改进的系统。

### 选择你的业务场景

从以下场景中选择一个（或者用你自己的场景）：

**场景 A：自动化客服 Agent**
- 用户发送自然语言请求
- Agent 访问知识库、CRM 系统、订单系统
- 需要回答问题、查询状态、提交工单

**场景 B：自动化数据 ETL Agent**
- 从多个数据源（MySQL、API、CSV 文件）收集数据
- 做清洗、转换、聚合
- 输出到数据仓库

**场景 C：代码审查 Agent**
- 监听 GitHub PR 事件
- 自动阅读代码变更
- 生成审查意见并发表评论

**场景 D：（用你自己的场景）**

## 📋 Capstone 交付物

**交付物 1：业务场景描述（1-2 段）**
描述你要解决的真实业务问题，包括：
- 主要用户是谁
- Agent 需要完成什么任务
- 成功的标准是什么

**交付物 2：Harness 架构图**
使用上面的模板（手绘或文字描述）填充你的架构

| 组件 | 当前状态 | 目标状态 | 优先级 | 预计工作量 |
